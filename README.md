# Simple Login Page

A full-stack application with a simple login page.

## Technologies
- Frontend: React with Vite
- Backend: Node.js with Express
- Database: SQLite

## Setup

### Backend
```bash
cd backend
npm install
npm start
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```

## Usage
1. Start both backend and frontend.
2. Open the frontend in browser (usually http://localhost:5173)
3. Register a new user with username and password.
4. Login with the credentials.

The backend runs on http://localhost:5000
